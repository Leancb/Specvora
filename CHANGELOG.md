# Changelog

All notable changes to Specvora are documented here. The project follows semantic versioning.

## 0.1.0 — 2026-09-08

First training MVP release.

### Product

- Deterministic OpenAPI analysis, scenario generation, traceability and quality gates.
- Controlled Pytest/HTTPX and Playwright generation, execution and normalized evidence.
- Explainable release-confidence assessment and hash-chained audit records.
- Human review, immutable promotion and a multi-project portal.

### Governance and security

- One-use Ed25519 execution approvals and durable CI approval consumption.
- Confined workspaces, exact destination allowlists and container egress policy generation.
- Signed portal sessions, local roles, CSRF protection, TOTP and recovery workflows.
- Transactional session, replay, throttling and security-event state with an HTTPS adapter.
- Strict OIDC validation, PKCE login, governed JWKS rotation and tamper-evident trust audit.
- Read-only OIDC monitoring, idempotent alert delivery and leased scheduled cycles.

### Deployment boundary

Version 0.1.0 is a local/training MVP. Production use still requires operated distributed state,
managed workload identity, TLS/key lifecycle operations, receiver ownership, retention and SLOs.
